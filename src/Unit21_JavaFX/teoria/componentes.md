
### 🔄 Equivalencias de Componentes (Para no perderte)

| En Java Swing | En JavaFX | ¿Para qué sirve? |
| :--- | :--- | :--- |
| `JFrame` | **`Stage`** | La ventana del sistema operativo. |
| `JPanel` / `Container` | **`Scene`** / **`Pane`** | El lienzo o escena donde pones las cosas. |
| `JButton` | **`Button`** | Botón de acción. |
| `JTextField` | **`TextField`** | Campo de texto de una línea. |
| `JLabel` | **`Label`** | Etiqueta de texto o imagen. |
| `JTable` | **`TableView<T>`** | Tabla tipada de datos. |
| `JList` | **`ListView<T>`** | Lista vertical dinámica. |
| `BorderLayout` / `GridLayout` | **`BorderPane`**, **`GridPane`**, **`HBox`**, **`VBox`** | Paneles de distribución modernos. |
